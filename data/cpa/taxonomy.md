## 第一部分：顶层结构（官方名称）

```
注册会计师全国统一考试
├── 专业阶段考试（6 科目，5 年内通过）
│     ├── 会计
│     ├── 审计
│     ├── 财务成本管理
│     ├── 税法
│     ├── 经济法
│     └── 公司战略与风险管理
└── 综合阶段考试（1 科目）
      └── 职业能力综合测试
            ├── 试卷一（50 分）
            └── 试卷二（50 分）
```

- **专业阶段**：6 科目，《会计》《审计》《财务成本管理》《税法》《经济法》《公司战略与风险管理》（官方教材正式名称，注意是“财务成本管理”而非“财务管理”）。
- **综合阶段**：设“**职业能力综合测试**”科目，分**试卷一、试卷二**（各 50 分）；**试卷一以鉴证业务为重点，涉及会计、审计和税法**；**试卷二以管理咨询和业务分析为重点，涉及财务成本管理、公司战略与风险管理和经济法**；试卷一设 5 分英文作答附加分。

## 第三部分：综合阶段（职业能力综合测试）

综合阶段**无独立教材**，官方文件为《2026 年注册会计师全国统一考试大纲——综合阶段考试》，其“考试科目”定义为：

```
职业能力综合测试（试卷一 + 试卷二，各 50 分；题型：综合案例分析；各 3.5 小时）
├── 试卷一（以鉴证业务为重点）：会计 + 审计 + 税法     （含 5 分英文附加分）
└── 试卷二（以管理咨询和业务分析为重点）：财务成本管理 + 公司战略与风险管理 + 经济法
```

大纲在综合阶段对各科目给出**“考试内容”条目**（即专业阶段章节的精简合并版），**不是教材的编/章结构**。例如：

- **会计**（试卷一）：按“（一）总论…（二十八）政府及民间非营利组织会计”共 **28 个内容板块**（2026 在新大纲中新增“（七）人工智能在会计审计领域的应用”）。
- **审计**（试卷一）：审计计划 / 风险识别和评估 / 风险应对 / 各业务循环 / 对特殊事项的考虑 / 完成审计工作与报告 / 企业内部控制审计 / **企业可持续信息鉴证** / 质量管理 / 职业道德 / 独立性要求等。
- **税法**（试卷一）：增值税法 / 消费税法 / 企业所得税法 / 个人所得税法 / 其他税种 / 国际税收 / 征管 / 行政法制。
- **财务成本管理**（试卷二）：财务管理概述 / 财务报表分析 / 价值评估基础 / 资本成本 / 投资项目资本预算 / 期权价值评估 / 企业价值评估 / 资本结构 / 长期筹资 / 股利分配 / 营运资本管理（仅财务管理模块，不含成本/管理会计）。
- **经济法**（试卷二）：法律基本原理、基本民事、物权、合同、合伙企业、公司、证券、企业破产、票据与支付结算、企业国有资产、反垄断、涉外经济法律制度。
- **公司战略与风险管理**（试卷二）：战略分析、战略选择、战略实施、公司治理、风险与风险管理等。

> **做题库时的建议**：综合阶段题目不要单独建“章”，直接**打标签归属到 试卷一（会计/审计/税法）或 试卷二（财管/战略/经济法）**，再映射到对应专业阶段的章，即可与大纲口径一致。
